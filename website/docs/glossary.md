# 术语速查

第一次遇到这些词时，不用急着背定义。把它们和正在阅读的实验、数据及代码对应起来即可。

## 数据与计算

| 术语 | 在本实验中怎样理解？ | 阅读位置 |
|---|---|---|
| 稀疏矩阵 | 大部分元素为零，本实验只保存 A 的非零元素。 | [Lab1 · CSR](lab1/csr.md) |
| 稠密矩阵 | 按完整行列范围保存元素。 | [Lab1 介绍](lab1/index.md) |
| CSR | 用非零值、列号和行起点三个数组保存稀疏矩阵。 | [CSR 教程](lab1/csr.md) |
| nnz | 非零元素总数；同样行数的稀疏矩阵可以有不同 nnz。 | [任务划分](lab1/parallel.md) |
| SpMM | 稀疏矩阵与稠密矩阵相乘。 | [Lab1 介绍](lab1/index.md) |
| tile／分块 | 从矩阵或任务空间中划出的一段局部范围。各实验的 tile 含义以参数页为准。 | [Lab2 教程](lab2/locality.md)、[Lab5 教程](lab5/tiling.md) |
| MAC／乘加 | 一次乘法，并将乘积累加到部分和。 | [PE 教程](lab5/architecture.md) |

## 并行程序

| 术语 | 在本实验中怎样理解？ | 阅读位置 |
|---|---|---|
| 线程 | 同一进程中的执行参与者，可以访问共享内存。 | [Lab1 教程](lab1/parallel.md) |
| 静态调度 | 在循环开始时分配任务。 | [任务划分](lab1/parallel.md) |
| 动态调度 | 线程完成任务后继续领取剩余任务。 | [任务划分](lab1/parallel.md) |
| 负载均衡 | 尽量让参与者承担相近的实际工作量。 | [Lab1 教程](lab1/parallel.md) |
| 局部性 | 让同一或相邻数据在较短间隔内被使用。 | [Lab2 教程](lab2/locality.md) |
| 临界区 | 需要互斥执行的一段操作。 | [Lab3 教程](lab3/synchronization.md) |
| 原子操作 | 不被其他相应并发更新拆开的单次操作。 | [Lab3 教程](lab3/synchronization.md) |
| 屏障 | 参与者到齐后才能继续的同步点。 | [线程统计](lab1/parallel.md) |
| rank | MPI 通信组中的进程编号。 | [MPI 教程](lab4/mpi.md) |
| 集合通信 | 通信组中的进程共同参与的数据交换，例如广播或收集。 | [MPI 教程](lab4/mpi.md) |
| 非阻塞通信 | 发起通信后先返回，通过请求在需要时等待完成。 | [通信重叠](lab4/communication.md) |

## 硬件仿真

| 术语 | 在本实验中怎样理解？ | 阅读位置 |
|---|---|---|
| RTL | 用寄存器和逻辑描述时钟推进下的电路行为。 | [Lab5 介绍](lab5/index.md) |
| PE | 执行乘加并传递相邻数据的处理单元。 | [架构教程](lab5/architecture.md) |
| 脉动阵列 | 数据沿相邻 PE 逐拍流动的二维计算阵列。 | [架构教程](lab5/architecture.md) |
| SPM | 明确安排加载和覆盖的局部工作空间。 | [架构教程](lab5/architecture.md) |
| bank／存储分区 | SPM 内能分别读写的存储分区，用于同时提供多行或多列数据。 | [架构教程](lab5/architecture.md) |
| DMA | 在软件 DRAM 与 SPM 之间搬运数据的模块。 | [架构教程](lab5/architecture.md) |
| 双缓冲 | 计算当前块时，用另一个缓冲区准备下一块。 | [分块教程](lab5/tiling.md) |
| 数据拍／beat | 一次握手传输的数据单位，本实验为 64 位。 | [供数接口](lab5/architecture.md) |
| VCD | 保存信号随仿真时间变化的波形文件。 | [Lab5 操作步骤](lab5/run.md) |

## 测量

| 术语 | 在本实验中怎样理解？ |
|---|---|
| 基准配置 | 用来比较的配置，计算加速比前需要明确它。 |
| 加速比 | 基准时间或周期除以当前时间或周期。 |
| 中位数 | 将重复记录排序后位于中间的数值。 |
| checksum | 输出元素总和，是摘要而非逐元素验证。 |

这些数值怎样一起阅读，见[怎样测量程序](preparation/measurement.md)。
